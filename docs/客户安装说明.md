# Nod 开源版 — 安装与使用说明

## 安装

二选一：

- **Nod Setup 1.1.0.exe**：安装版（推荐）。双击 → 下一步 → 完成，桌面出现 Nod 图标。
- **Nod 1.1.0.exe**：绿色版，免安装，双击直接运行（U 盘拷贝可用）。

> 关于安全提示（本版本未签名）：
> 本版本尚未购买代码签名证书，Windows 首次运行可能显示 SmartScreen「未知发布者」提示，
> 部分杀毒软件也可能误报（PyInstaller 打包程序常见特征）。请先用附带的 `SHA256SUMS.txt`
> 核对文件校验值（命令行 `certutil -hashfile <文件> SHA256`），确认哈希一致后再决定是否继续。

## 首次运行：填写 API Key

首次启动会弹出「需要 API Keys」面板，需要填写两个 key（都**只保存在本机** `%APPDATA%\Nod\secrets.json`，不会上传给作者或任何第三方）：

1. **OpenRouter API Key**（AI 回答）—— 到 [openrouter.ai/keys](https://openrouter.ai/keys) 注册并创建 key（有免费额度）。
2. **AssemblyAI API Key**（语音转写）—— 到 [assemblyai.com/app](https://www.assemblyai.com/app) 注册并创建 key（有免费额度）。

填好点「保存并开始」即可使用。想更换 key 时，删除 `%APPDATA%\Nod\secrets.json` 再重启即可重新填写。

## 使用

1. 打开 Nod 窗口，按 **F3** 开启 Auto Listen（状态栏显示 *Listening for the next question…*）
2. 在 Teams / Zoom 里说话（或播放面试官提问音频），声音从扬声器/耳机出来
3. Nod 自动捕捉问题 → 生成答案 → 显示在窗口里（可直接复制）
4. 也可直接点底部输入框打字提问

## 配置与个性化

配置存放在 **`%APPDATA%\Nod\config.json`**（在资源管理器地址栏输入该路径即可打开），**不是**安装目录。可编辑：

- `profile.resume_summary` — 简历摘要
- `profile.target_role` / `company` / `jd` — 目标岗位 / 公司 / 岗位要求
- `profile.style` — 回答风格

修改后重启 Nod 生效。

## 快捷键

| 按键 | 功能 |
|---|---|
| F2 | 手动录音提问 |
| F3 | Auto Listen（自动听题回答） |
| F4 | 清空对话 |
| F8 | 全屏 / 窗口切换 |
| F9 | 隐身模式（录屏时隐藏窗口） |

## 网络要求

- 语音识别走 **AssemblyAI 云端**（你填写的 key），需联网。
- AI 回答走 **OpenRouter 云端**（你填写的 key），需联网。

## 隐私说明（请阅读）

| 数据 | 处理方 | 用途 |
|---|---|---|
| 面试提问音频（实时流，本地不落盘） | AssemblyAI（美国） | 语音转写 |
| 提问文本 + 简历/岗位描述 | OpenRouter（及其上游模型，境外） | 生成回答 |
| 问题与答案历史（仅内存，退出即清空） | 本地 | 上下文与去重 |

- **使用谁的额度**：你填写的 key 用的是**你自己的账号**，用量计入你自己的 AssemblyAI / OpenRouter 账户。
- **保存多久**：本地不保存任何音频或对话，退出即清空。但音频流与提问会发送到第三方服务商——AssemblyAI 默认可能在其账户保留转写记录（按其数据保留政策），OpenRouter 及上游模型按各自政策可能记录请求/响应。
- **如何撤回同意**：① 卸载 Nod 即停止一切数据发送；② 删除 `%APPDATA%\Nod\config.json` 中的 `profile` 字段即停止上传简历等个人化数据；③ 删除 `%APPDATA%\Nod\secrets.json` 即移除你的 key；④ 如需删除已发送到第三方的历史数据，请联系相应服务商（AssemblyAI / OpenRouter）申请删除。
- **不要输入不愿与第三方共享的敏感信息。**
