# Nod 封装保护与法律风险方案

> 对象：Nod（interview-pilot，AI 面试助手）
> 日期：2026-08-16 ｜ 语境：新西兰（NZ Privacy Act 2020 / GST / CGA）

---

## 一、先盘点你的资产（决定保护力度）

| 资产 | 位置 | 泄露后果 | 保护成本 |
|---|---|---|---|
| **API Keys**（DeepSeek / OpenRouter / AssemblyAI） | `Hermes .env`，引擎侧读取 | 最高——被人盗用刷钱 | **已隔离 ✓**（前端永远读不到，Electron 不打包 .env） |
| Python 引擎 `app.py`（核心逻辑） | 项目根，明文 | 中——复制你的实现 | 打包成 exe（本篇 L1） |
| 前端 JS（React 编译产物） | `desktop/dist` | 低——UI 逻辑不值钱 | 已压缩，asar 包（L2） |
| `config.json`（简历/JD 等个人数据） | 项目根 | 中——个人隐私 | 打包时排除，首次运行生成 |
| 用户音频（流式处理） | 不落盘 | — | 引擎设计已不保存 ✓ |

**诚实结论：客户端保护是"防君子不防小人"**——任何本地软件都能被逆向，保护的目标是让普通用户拿不到源码、让破解成本高于买一个，而不是绝对不可破解。你真正的护城河是 **API key 不泄露 + 服务端可控**，这个你已经做对了。

## 二、技术保护（分层实施）

### L1：Python 引擎打包（必做，防源码泄露）

用 PyInstaller 把 `app.py`（含 faster-whisper / sounddevice / PyQt5）打成 `nod-engine.exe`，分发时不带 `.venv` 和源码。

```bash
# pack_engine.bat（已提供）
.venv\Scripts\pyinstaller.exe --noconfirm --clean ^
  --name nod-engine --onedir ^
  --collect-all faster_whisper --collect-all ctranslate2 ^
  --add-data "config.json;." ^
  app.py
```

- **onedir 优于 onefile**：启动快（onefile 每次解压，faster-whisper 模型加载已够慢）、杀软误报少
- 体积警告：faster-whisper + ctranslate2 打包后约 **300–500 MB**，这是本地 STT 的代价；如果只用云端 AssemblyAI 可加 `--exclude-module faster_whisper` 瘦身
- Electron 侧：`bridge.ts` 的 spawn 目标从 `.venv\Scripts\python.exe app.py --bridge` 改为 `nod-engine.exe --bridge`

### L2：Electron 打包成安装程序（分发形态）

用 electron-builder 出 Windows 安装包（`desktop/electron-builder.yml` 已提供）：

```yaml
appId: com.nod.app
productName: Nod
asar: true                    # 前端 JS 封进 asar（默认防手贱解包）
win:
  target:
    - nsis                     # 安装版
    - portable                 # 免安装单文件
files: [dist-electron, dist, assets]
extraResources:               # 引擎 exe + 模型放 resources
  - from: ../dist/nod-engine
    to: engine
```

- `nsis` 出安装程序（桌面图标、开始菜单、卸载）
- `portable` 出单文件绿色版（U 盘分发用）
- **asar 加密**：`electron-builder` 的 `asar: true` 只防手贱；真要防逆向需 asar 加密插件（`@electron/asar` + 自定义 crypto），但收益低，不建议为 UI 逻辑花这个钱

### L3：授权 / 试用限制（可选，收费才需要）

- **单机授权**：首次运行生成机器码（CPU 序列号 hash）→ 发给你 → 你给注册码（HMAC 签名）。引擎侧校验，代码 50 行内
- **在线激活**：你的服务器验证 key + 记录激活次数（防多机共用）。需要你有服务器（你已有 Hostinger VPS）
- **诚实提醒**：授权校验本身也能被 patch 绕过（改一行跳转）。对个人工具，贴个 LICENSE 文本 + 伦理约束就够了

### 打包时的坑（本项目实测踩过）

1. **PYTHONPATH 污染 → numpy 崩溃**：本机终端 PYTHONPATH 指向 hermes-agent venv（cp311 numpy）。打包命令**必须 `env -u PYTHONPATH`**，否则 PyInstaller 收集到 cp311 numpy，exe 启动即 `ModuleNotFoundError: numpy._core._multiarray_umath`（实测第一次打包就这样崩）。运行打包 exe 同样要 `env -u PYTHONPATH`（bash 里）。
2. **PyQt5 是 GPL 且顶层 import 无法排除**：app.py 顶层 `from PyQt5.QtCore import ...`（Pipeline 信号 + bridge 的 QCoreApplication），`--exclude-module PyQt5` 会让引擎直接 ImportError。**PyQt5 会随包分发**（GPL 传染）：个人/测试分发可接受，**商用闭源前必须重构**——把信号层换成纯 threading/无 PyQt（或换 LGPL 的 PySide6），工作量中等。LICENSE 已注明。
3. **绝对不要把 `.env` / 简历 config 打进安装包**：`config.json` 会随引擎分发，打包前确认里面没有你的个人简历敏感数据；`api_key` 字段是给客户测试版的兜底（7 天 key），正式商用应改为首次运行引导填 key。
4. **杀软误报**：PyInstaller + 全局热键 hook 易触发 Defender/学校杀软误报；正式发布需代码签名（EV 证书 ~$300/年）。
5. **electron-builder 坑**：`bridge.ts` 需按 `app.isPackaged` 切换引擎路径（开发 = `.venv python app.py --bridge`；打包 = `resources/engine/nod-engine.exe --bridge`，cwd = 引擎目录）；打包版 config.json 在 `_internal/` 下，引擎 `BASE_DIR` 自动指向那里 ✓。

## 三、法律风险（新西兰语境）

### 3.1 最大风险：面试作弊的合规性质

Nod 的核心用途是"实时面试辅助"。风险分层：

- **学校作业演示**（你的 SOFT605 场景）：低风险，教学用途
- **真实求职面试**：中高风险——绝大多数公司面试政策禁止实时 AI 作答；线上面试平台（Teams/Zoom）可检测置顶悬浮窗与后台音频监听（README 已注明）。**若被认定欺诈，后果是 offer 取消 / 行业信誉受损 / 学校纪律处分**
- **认证类考试**：高风险——可能构成学术欺诈

**必须写进 DISCLAIMER 的表述**（已写入 `DISCLAIMER.md`）：
> 本软件仅供学习与技术演示。在真实面试/考试中使用实时 AI 作答可能违反雇主政策、学术诚信准则或平台条款，使用者自行承担全部责任。

### 3.2 隐私（NZ Privacy Act 2020）

| 行为 | 合规评估 |
|---|---|
| 监听/录制对话声音 | NZ 采**一方同意**原则——你参与的对话可录制。但 Nod 流式处理、**不保存音频** ✓（比录音软件合规风险低） |
| 音频 → AssemblyAI（美国服务器） | 跨境传输个人信息（声音属个人可识别信息）。需**告知用户**（隐私声明里写明"音频由 AssemblyAI 处理"） |
| 简历/JD → DeepSeek（中国服务器） | 同上，需告知。**提示**：上传简历到境外 LLM 是用户主动行为，条款里写明即可 |
| 收集信息最小化 | Nod 只收简历/JD/提问，不收集姓名邮箱等 ✓ |

**给你的行动项**：隐私声明写清楚"哪些数据发给哪些服务商"（DISCLAIMER.md 已含），别写"我们不会分享你的数据"这种假话——音频和简历确实发给了第三方。

### 3.3 分发与免责（NZ Consumer Law）

- **"按现状提供"（AS-IS）**：对 B2B / 开发者用户有效；对**消费者**（CGA 消费者保障法）免责条款效力受限——如果收费卖给普通个人，CGA 要求"可合理预期的工作质量"。**定价卖"开发者工具/试用版"而非"面向消费者的成品服务"能降低这层风险**
- **GST**：年营业额 ≤ NZ$60,000 无需注册 GST（你个人私活规模远低于此）；超过要注册并加收 15%
- **出口/再分发**：禁止用户二次分发你的打包物（写进 LICENSE）

### 3.4 知识产权

- 代码版权默认归你（NZ Copyright Act 1994），无需注册
- **第三方许可自查**（打包分发前）：faster-whisper(MIT)✓、Electron(MIT)✓、React(MIT)✓、soundcard(BSD)✓、**PyQt5(GPL)✗ 需处理**（见二.1）、AssemblyAI/DeepSeek 是 API 服务（条款约束使用而非代码）✓

## 四、建议的执行顺序

1. **现在**：README 免责段 → 引用 `DISCLAIMER.md`（已改）
2. **要发给别人时**：跑 `pack_engine.bat` 打引擎 exe → 配 `electron-builder.yml` 出安装包（首次打包需下载 electron-builder，约 100MB）
